# Synthetic order-line data dictionary

All columns except `customer_segment` and `campaign` are required and non-null in
`insightai-orders.csv`. The two optional dimensions use an empty CSV field for deterministic
not-reported/unattributed cases. Monetary values are USD row or unit amounts serialized with two
decimal places. Identifiers are synthetic opaque labels.

## Grain warning

The CSV has 6,909 rows but only 4,310 orders. Multi-product orders repeat `order_id` and have unique
`order_line_id` values. Product/category slices may count a distinct order if any selected line from
that order is present, matching the future analytics specification.

## Optional-value interpretation

Future ingestion should map blank `customer_segment` and `campaign` fields to null while retaining
the complete row. Whole-dataset revenue, cost, order, customer, and repeat-customer metrics still use
those rows. Dimension breakdowns may display an explicit `Unknown` customer segment or
`Unattributed` campaign member, but must not silently drop blank values or infer a label from another
field. Every other column is required; a blank in any required field is a validation error.
